Edits and fixes to the Axoloti factory library.

New content will not be added to this library, however bugfixes and improvements will be made as required.

Starting with version 1.1.0, some patches and objects might become incompatible with the original Axoloti Patcher (1.0.12)! However Ksoloti Patcher 1.0.12 is still supported and objects are updated if compatibility is ensured.
